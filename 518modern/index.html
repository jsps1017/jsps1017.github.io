데이터 v0.3 · 데모
지도 사적지 인물 언론 분석 사건 데이터 AI 리포트 데이터·API 갱신 이력 소개

데모입니다. 공개 출처의 서술을 요약한 예시 레코드이며 사실 검증과 권리 확인을 거치지 않았습니다. 좌표 일부는 근사치입니다. 전남광주인문사회연구원의 공식 서비스가 아닙니다. 이 게시본은 2026.11.24 판(데이터 v0.4)이며, AI 리포트를 새로 쓰는 시연 기능은 여기서 작동하지 않습니다.

연구자 보기(시연) · 신청·승인한 연구자에게 줄 정보가 더해집니다: 레코드별 출처 상세·자동 점검·변경 이력, 위치 불확실 범위, 검토 대기 리포트, 연구자용 내려받기. 내부 한정 자료(권리 미확정·개인정보 포함)는 넣지 않았습니다.

사적지 프로필

광주시 5·18사적지 제1~30호(제5호는 세부 사적 4곳)를 33개 레코드로 담았습니다. 카드를 누르면 사진, 장소의 변화, 보고서 기준 현황, 관련 인물이 담긴 프로필이 열립니다.

미지정 현장

2016년 보고서(전남대 5·18연구소)가 '사적지 지정 이외의 주요 현장'으로 꼽은 25곳 가운데 아직 사적지가 아닌 22곳입니다. 보고서가 적은 위치와 주요 사건, 사실에 해당하는 비고만 옮겼고, 날짜가 있는 사건은 사건 레코드로도 만들었습니다. 좌표는 OpenStreetMap 지물로 잡은 근사값입니다. 위의 자치구·정밀도 고르기가 여기에도 적용됩니다.

사적지 제도의 변화

지정, 표지석 설치, 조례 제정·개정 가운데 보고서에 날짜가 있는 사실입니다.

    관련 인물

    공개 출처가 서술한 역할만 적고, 그 역할이 일어난 사적지와 잇습니다. 생존 인물은 출처에 나온 공개 역할만 다루며 인물 사진은 넣지 않았습니다. '지도에서 보기'를 누르면 기록된 장소를 날짜순으로 잇습니다.

    언론 기사 텍스트마이닝

    기사 표본을 불러오는 중입니다.

    월별 주제 구성

    달마다 15건을 뽑았으므로 막대 높이는 같고, 색 칸은 그달 기사 가운데 각 군집에 배정된 기사 수입니다.

    기사에 나온 사적지

    사적지를 가리키는 표기가 나온 기사 수(표본 180건 중). 누르면 해당 기사를 모아 봅니다.

    감성·감정 분석

    달마다 감성 톤

    많이 나온 감성어

    KNU 한국어 감성사전 항목이 나온 횟수(표본 전체)입니다.

    주제 군집별 감성과 감정

    부정 문장이 많은 군집부터 놓았습니다. 군집 이름을 누르면 위 네트워크와 오른쪽 목록이 그 군집으로 바뀝니다.

    감정어 지도

    점 위치는 원 연구가 매긴 정서가·각성가(5단계 척도 값)이고, 크기는 이 표본에서 나온 횟수입니다.

    방법과 한계

      사건 데이터

      ACLED 코드북을 준용한 사건 단위 레코드입니다. 시간·위치 정밀도와 출처별 수치를 함께 기록합니다. 행을 누르면 상세 기록이 열립니다.

      AI 자동 리포트

      AI가 데이터 변경과 함의를 리포트로 씁니다. 문장마다 근거 레코드가 붙고, 수치와 레코드 연결은 기계가 자동으로 검사합니다. 서술의 사실 여부와 해석은 연구자가 판단합니다.

      데이터 내려받기·읽기 전용 API

      데이터는 정적 파일(JSON) 방식의 읽기 전용 API로 제공합니다. 서버 없이도 운영할 수 있는 구조입니다.

      갱신 이력
      
    
      데이터는 버전별로 배포하고 변경 내역을 남깁니다. 변경이 생기면 수정사항 리포트가 자동으로 만들어집니다. v0.1·v0.2는 데모 시나리오이고, v0.3은 보고서 세 권의 사실을 옮긴 갱신, v0.4는 자유 이용 사진을 보탠 갱신입니다.
      
    
      
    
        
  
        

  
        
    
        
      
        
        
        무엇을 보여 주는 데모인가
        
        
        5·18 사적지와 5·18 데이터를 하나의 AI 아카이브로 묶고, ACLED식으로 웹에 공개하며, 데이터가 바뀌면 AI가 리포트를 쓰는 구조를 작동하는 화면으로 보여 줍니다.
        
        
        AI 아카이브는 자료의 축적에서 결과 공개까지 연구데이터 전 주기(축적–전처리–보존·관리–분석–공개)에 AI가 관여해 연구자를 지원하는 통합 시스템입니다. 단계마다 연구자 검증을 전제로 합니다.
        
        
        화면과 구상서의 대응
        
        
        
          
        화면구상서 항목
        
          
            
        지도Ⅳ. 웹 공개: 지도 뷰어(시간·유형 필터, 위치 정밀도 표시, 1990~2020 위성영상 시점 비교)
        
            
        사적지Ⅳ. 웹 공개: 사적지 프로필(사진, 장소의 변화, 보고서 기준 현황, 관련 사건·인물, 구술 연결 자리), 미지정 현장
        
            
        인물Ⅲ. 데이터 구조: 인물–장소 연결(출처가 서술한 역할 단위)
        
            
        언론 분석분석 단계 예시(데모에 더한 기능): 언론 기사 텍스트마이닝, 단어 네트워크·주제 군집, 사적지 언급 집계, 감성·감정 분석(공개 사전 기반)
        
            
        사건 데이터Ⅲ. 데이터 구조: ACLED 코드북 준용, 출처별 수치 병기
        
            
        AI 리포트Ⅴ. AI 자동 리포트: 근거 기반 생성, 수치 자동 대조, AI 생성 표시
        
            
        데이터·APIⅣ. 웹 공개: 내려받기·읽기 전용 API, 공개 등급
        
            
        통합 검색(머리)데모에 더한 기능: 사적지·미지정 현장·사건·인물·출처를 한 칸에서 찾기(출처 제목·ID는 연구자 보기에서)
        
            
        전체 공개·연구자 보기Ⅳ. 웹 공개: 공개 등급별 화면(연구자 공개 범위: 출처 상세, 레코드별 자동 점검·변경 이력, 검토 대기 리포트, 연구자용 내려받기). 내부 한정 자료는 넣지 않음
        
            
        갱신 이력Ⅳ. 웹 공개: 갱신 이력, 버전별 배포
        
                  
        
        
        
        데모의 한계
        
        
          
          
        • 공개 출처(정부 누리집, 언론 보도, 디지털인문학 위키)와 5·18기념사업 마스터플랜 보고서(2016·2021)의 서술만 옮기거나 요약했습니다. 권리 확인이 필요한 '5·18 데이터'는 넣지 않았습니다.
          • 
          
        • 사실 검증 전 예시 레코드입니다. 피해 수치는 공식 기준값을 비워 두고 출처별 수치만 일부 넣었습니다.
          • 
          
        • 사적지 좌표 가운데 일부는 대표점·근사·추정 좌표입니다. 지도에서 정밀도별로 다르게 표시합니다.
          • 
          
        • 연도별 지도는 Landsat 위성영상(30m 해상도)입니다. 시가지 확장이나 큰 부지의 변화는 보이지만 건물 하나하나의 변화는 보이지 않습니다. 1990~2020년 무렵의 옛 도로·건물 지도와 항공사진(국토지리정보원)은 이 데모 환경에서 받을 수 없어 넣지 못했습니다.
          • 
          
        • 배경 지도는 지금의 OpenStreetMap이라 옛 영상과 겹쳐 보면 그 시점에 없던 도로가 함께 보입니다.
          • 
          
        • 장소의 변화는 출처에서 확인한 항목만 넣었습니다. 항목이 없는 사적지는 변화가 없다는 뜻이 아니라 아직 입력하지 않았다는 뜻입니다.
          • 
          
        • 사진은 위키미디어 공용과 대한민국역사박물관 근현대사아카이브의 자유 이용 사진(CC BY-SA·CC BY·CC0·공공누리 제1유형 등)만 썼고, 인물 사진은 넣지 않았습니다. 사진이 없는 사적지와 미지정 현장이 있습니다.
          • 
          
        • 구술 자료는 권리 확인 후 연결하는 자리만 두었습니다(IWM·NHK 공개 모델 참고).
          • 
          
        • 언론 분석은 다음 뉴스 정확도순 표본 180건(달마다 15건)을 사전 없는 간이 명사 추출로 분석한 예시입니다. 군집 이름은 해석이며, 연구에 쓰려면 빅카인즈 등의 전체 기사와 형태소 분석기로 다시 분석해야 합니다. 감성·감정은 공개 사전(KNU 한국어 감성사전, 박인조·민경환의 감정단어 목록)으로 자동 판정한 값이라 반어·인용·맥락을 읽지 못합니다. 기사 본문은 저장하지 않았습니다.
          • 
          
        • 갱신 이력의 v0.1·v0.2는 기능 시연을 위한 가상 시나리오입니다. v0.3은 전남대 5·18연구소 보고서 세 권(2016년 본책·별책, 2021년)의 사실을 옮긴 갱신이며, 보고서의 제안(명칭 개정, 표지석 위치 조정, 활용 계획)은 넣지 않았습니다.
          • 
          
        • 보고서 기준 현황과 미지정 현장은 보고서 표기를 그대로 옮겨 원문의 오기가 남아 있을 수 있습니다(예: 505보안부대 옛터 '남구 쌍촌동'). 미지정 현장의 좌표는 OpenStreetMap 지물로 잡은 근사값이고, 건물을 찾지 못한 곳은 동 수준 추정으로 표시했습니다.
